Frontend Fastrack:

The HTML/CSS Cheatsheet

Starter Tags: HTML

Name of element Tag What it does! Things to Note
HTML Opening <!DOCTYPE> Explains that the document is written in HTML Entered at the top of the index.html
Header <head> Stores the metadata needed to access the index.html Can include titles and fonts etc.
Link <link> Adds links within the page (inc. CSS) <link href= "..." rel: "stylesheet" type="text/css">
Link Part II target = "_blank" To open link in a new window/tab <a href="URL" target=_blank>
Anchor < a > Links to other pages/jump to a specific spot/download files <a href="URL">
Using an anchor tag on an image <a href="URL"> < img src="...">
Unordered Lists <ul> Enables text to be displayed as a list <ul> then utilises a list element for text
Ordered Lists <ol> Enables text to be displayed as an ordered list <ol> then utilises a list element for text
List <li> Formats text as a list item <ol> or <ul> then utilises a list element for text
Body <body> The main content of the website Use opening and closing tags after header
Headings <h1> The titles within the webpage Titles can range from 1-6 (1 being the main)
Text/Paragraphing <p> Text within a webpage
Footer <footer> Includes elements at the bottom of a webpage May include contact details, attributes, privacy policy etc.
Comments <!--comment--> Where developer can add notes to the file May include sectioning, labels etc.

Multimedia: HTML

Inserting multimedia elements inside your webpage:

Name of element Tag What it does! What the code looks like Things to Note
Images <img> Inserts an image or acknowledges image <img src="url/relative path" height="..." width="..."> Does not need a closing tag
Video <video> Inserts a video into a webpage <video src="..." controls> Unlike images, this needs a closing tag. Also include 'Video not supported'
Audio <audio> Inserts audio into a webpage <audio src="..." controls> Like videos, this needs a closing tag

Table Tags: HTML

Inserting table elements inside your webpage:

Name of element Tag What it does!
Table <table> Identifies the start of a table element
Table Head <thead> Defines the beginning of table
Table Row <tr> Identifies the table row and should be used from the table headings
Table Body <tbody> Identifies the main body of the table
Table Headings <th> These are the headings of each row or column
Table Data <td> Data contained within cells
Table Footer <tfoot> Information in the footer of the table
Merging Columns <colspan=...> Identify the number of columns to merge or span
Merging Rows <rowspan=...> Identify the number of rows to merge or span
